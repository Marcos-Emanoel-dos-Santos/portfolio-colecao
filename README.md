# Portfólio | Criações

Portfólio e Coleção de Criações mais significativas feitas por mim no decorrer da minha vida acadêmica.

## Como rodar

O site pode ser acessado diretamente através [deste link](https://marcos-emanoel-dos-santos.github.io/portfolio-colecao/) ou o repositório pode ser clonado com
```
git clone https://github.com/Marcos-Emanoel-dos-Santos/portfolio-colecao.git
```

Por não haver backend, simplesmente abra o arquivo index.html e o site estará disponível em seu navegador.



## Motivação

Este site foi feito com o propósito inicial de ser um portfólio e coleção de criações para a primeira etapa do processo seletivo da Apple Developer Academy turma 27/28, porém, no decorrer de sua idealização decidi não fazer apenas um portfólio, mas um reflexo do que sou.

Esta aplicação não é totalmente colorida sem razão, e sim porque foram as cores (mais precisamente, LEDs coloridos) que deram início à minha trajetória na computação.



## Declaração de Uso de IA

Gemini Pro 3.1 foi utilizado no decorrer da criação deste projeto a fim de:
- corrigir bugs de estilização
- criação das animações das estrelas e carrossel.
